## Description

This is a simple two-player Rock Paper Scissors game made using Dart.
Players enter their names, choose rock, paper, or scissors, and the
program determines the winner and keeps track of the score.

The game also allows players to play multiple rounds and shows the final
score after the game ends.

## How to Run

Open the terminal in the project folder and run:

```bash
dart rock_paper_scissors.dart



## Game Rules
- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- Same moves result in a draw
